# AEGIS

## Autonomous Enterprise Global Intelligence System

**Company:** Honeydewnuts Nigerian Limited

---

## Overview

AEGIS is an AI-powered trading intelligence and autonomous execution platform designed to analyze financial market charts using computer vision, artificial intelligence, and advanced trading algorithms.

The platform is being developed with a cloud-first architecture, using Python for the backend AI engine and a web-based frontend for cross-platform accessibility.

---

## Technology Stack

### Backend

- Python 3.12+
- FastAPI
- OpenCV
- PyTorch
- Ultralytics YOLO
- PostgreSQL
- Redis

### Frontend

- Next.js
- React
- TypeScript
